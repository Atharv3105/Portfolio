---

## ✨ Key Features

- 🌌 **Interactive 3D Workspace Scene**: Built using **Three.js** featuring a dynamic developer setup with custom lighting, glowing IDE windows, and smooth mouse interaction.
- ⚡ **Typewriter Hero & Live Stats**: Highlighting core credentials, including **450+ GitHub Commits**, **200+ LeetCode Problems Solved**, **8.62 CGPA**, and **5+ Shipped Projects**.
- 🛠️ **Categorized Skills Matrix**: Full stack proficiency breakdown across Frontend, Backend, Database, Cloud & DevOps tooling.
- 🚀 **Featured Projects Showcase**: In-depth project cards with live production links, GitHub repositories, architecture summaries, and key tech badges.
- 🏆 **Interactive Hackathon & Achievements Matrix**:
  - Filterable by categories (*Hackathons*, *Global Challenges*, *Hiring Competitions*).
  - Chronological visual timeline stepper (*2025 - 2026*).
  - Live spotlight preview stage breaking down project impact, key highlights, and technology stack.
- 🎨 **Glassmorphic Cyber Aesthetics**: Tailored dark theme (`#091434`), neon orange (`#FF923E`) and cyan (`#34BFFF`) glow accents, smooth scroll reveals, and a dual-ring custom cursor.
- 📱 **Fully Responsive**: Optimized for seamless viewing across mobile, tablet, and desktop monitors.

## 🚀 Getting Started

Follow these steps to run the portfolio locally on your machine:

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18+ recommended) installed on your system.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Atharv3105/Portfolio.git
   cd Portfolio
   ```

2. **Install project dependencies:**
   ```bash
   npm install
   ```

3. **Start the Vite development server:**
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173` (or the port displayed in your terminal).

---

## 📜 Available Scripts

In the project directory, you can run:

- `npm run dev` — Launches the Vite development server with hot module replacement (HMR).
- `npm run build` — Compiles and minifies the application into production-ready static assets in the `dist/` directory.
- `npm run preview` — Locally previews the built production bundle.
- `npm run format` — Formats source code using `oxfmt`.
